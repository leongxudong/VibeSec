# Security Policy

VibeSec is a defensive security-review project. Please use it only on repositories and systems you own or are authorized to assess.

## Reporting a vulnerability in VibeSec

Please avoid publishing working exploit details for a vulnerability in VibeSec before the maintainer has had a reasonable opportunity to review and fix it. Open a GitHub issue for non-sensitive security concerns. For sensitive reports, contact the repository owner through the contact method listed on their GitHub profile.

## Scope

VibeSec v0.1 performs static source analysis and does not intentionally execute target application code or actively attack deployed services.
